# ഡിജിറ്റൽ ജീവിതത്തിൻ്റെ നിയന്ത്രണം — Digital Awareness Workshop

An animated, comic-book style presentation (Malayalam) for a 3-hour digital wellness workshop for students.

## How to use
- Open `index.html` in any modern browser (works offline — the Noto Sans Malayalam font and all images are embedded).
- Next / previous: arrow keys, spacebar, click, or swipe on a tablet.
- Fullscreen: press `F` or the **FULL** button.
- Jump to a slide: add `#slide-5` (etc.) to the address.

## Notes
- The hero and villain characters and the comic decorations are original drawings made for this deck.
- Image credits are listed on the last slide.
